## 🚀 How to Run & Preview

### Option 1: Direct File Open (Zero Install)
Simply double-click [`portfolio/index.html`](index.html) to open it in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari, Brave).

### Option 2: Local HTTP Server (Node.js)
If you prefer running via a local server:
```bash
node portfolio/serve.js
```
Then navigate to: **`http://localhost:3000`** in your browser.
